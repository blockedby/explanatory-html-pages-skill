Reservation vocabulary and stored data

Available stock
Units that can be promised now: on-hand units minus active holds and committed allocations.
Hold
A temporary claim on stock. In API names, a hold is called a reservation.
Allocation
A confirmed claim awaiting fulfillment; it no longer expires as a checkout hold.
Expiry
The instant after which an active hold cannot be confirmed, even if the cleanup worker has not run yet.
