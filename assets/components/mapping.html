Map checkout input to an inventory reservation

The adapter accepts a single basket line per request. It validates the line before calling Inventory; it does not silently round quantities or substitute another item.

Source → target transformations and failure behavior
Checkout sourceInventory targetTransformationMissing or invalid input
line.productCodeskuCopy unchanged, including case.Reject an empty value; never trim into a different SKU.
line.unitsquantityAccept an integer from 1 through 100.Reject strings, fractions, zero, and negative numbers.
attempt.idIdempotency-Key headerReuse the attempt ID for retries of this exact line and quantity.Stop if absent. A changed basket starts a new attempt.
Service identityOwning clientInventory derives ownership from the access token.Reject unauthenticated requests and any caller-supplied ownership field.

Worked example: {"productCode":"SKU-42","units":2} becomes {"sku":"SKU-42","quantity":2}. The attempt ID belongs in the header, not the JSON body.
